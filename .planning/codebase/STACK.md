## Configuration

**Environment:**

Backend (`app/app.py`):
- `OPENAI_API_KEY` - OpenAI API authentication token (required for ChatCompletion and Realtime APIs)
- `SUPABASE_URL` - Supabase project base URL (required for admin operations)
- `SUPABASE_SERVICE_ROLE_KEY` - Supabase service role secret key for admin API access (required for user management)

Frontend (`frontend/frontend-app/src/`):
- `REACT_APP_SUPABASE_URL` - Supabase project URL (environment variable for React)
- `REACT_APP_SUPABASE_ANON_KEY` - Supabase anonymous public key for client-side auth (environment variable for React)
- `REACT_APP_FLASK_API_URL` - Flask backend API base URL (defaults to `http://127.0.0.1:5000` for local development, set to Vercel endpoint in production)

## API & Network

**External API Endpoints Used:**

- OpenAI API (`https://api.openai.com/v1/`)
  - ChatCompletion endpoint for text conversation
  - Realtime (WebRTC) session endpoint for voice interaction
  - Whisper-1 model for audio transcription

- Supabase REST API (`${SUPABASE_URL}/rest/v1/`)
  - Profile queries and management
  - User authentication and admin operations
  - Can-Do statement queries
  - Session logging and transcription storage

- Supabase Auth API (`${SUPABASE_URL}/auth/v1/`)
  - User authentication token verification
  - Admin user management (create, delete, reset password)

**WebSocket:**

- OpenAI Realtime WebSocket: `wss://api.openai.com/v1/realtime?model=gpt-4o-realtime-preview`
  - Established from frontend after fetching ephemeral token from `/webrtc_session` endpoint

## Storage & Caching

**File Storage:**

- Frontend: Local filesystem only (no dedicated file storage integration detected)
- Backend: Static files served from `app/static/` and templates from `app/templates/` (deprecated frontend route removed for security)

**Session Management:**

- Flask server-side sessions stored in memory (`session` object in `app.py`)
- Supabase provides real-time database for persistent user data
